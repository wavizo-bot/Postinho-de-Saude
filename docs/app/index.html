Como instalar no Android

  1. Baixe o APK universal no próprio aparelho.
  2. Abra o arquivo. Se o Android pedir, permita “instalar apps desconhecidos” para o navegador ou gerenciador de arquivos usado.
  3. Confirme a instalação e abra o Postinho de Saúde. O jogo funciona offline.
  4. Se o Play Protect avisar que o app não é reconhecido, confira os detalhes e prossiga apenas se o SHA256 bater com o desta página.

O APK universal é para teste e instalação direta. A publicação na Google Play ainda depende de conta e credenciais externas; quando acontecer, o AAB desta mesma versão será o pacote enviado.

Como instalar no Windows

O MSIX é assinado com um certificado de teste próprio. Para instalar por sideload, importe o certificado público e depois instale o pacote. Execute o PowerShell como administrador para gravar nos repositórios locais da máquina:

Import-Certificate -FilePath .\PostinhoDeSaude-teste.cer -CertStoreLocation Cert:\LocalMachine\Root
Import-Certificate -FilePath .\PostinhoDeSaude-teste.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
Add-AppxPackage .\PostinhoDeSaude-1.0.1.0-x64.msix

Ou clique com o botão direito no .cer, escolha “Instalar Certificado”, selecione “Máquina Local” e coloque em “Autoridades de Certificação Raiz Confiáveis” e em “Editores Confiáveis”. Depois abra o .msix. O certificado serve apenas para teste local: a Microsoft Store reassina o pacote com o certificado da loja.

O que você está baixando

  • APK universal: instalação direta em Android arm64, assinado com a chave de release. Serve para teste e uso pessoal.
  • AAB: artefato para publicação na Google Play, com R8 full mode, minificação, shrinking e mapeamento de ofuscação. Não é instalável diretamente.
  • MSIX: pacote Windows x64 1.0.1.0, assinado para sideload. A Microsoft Store reassina o pacote na publicação.
  • Certificado .cer: chave pública do certificado de teste. Não contém a chave privada e não serve para assinar outros pacotes.
